# Test Questions

Use this file to test the first version before real customers use it.

## Basic Questions

1. 你们是做什么的？
2. 这个服务适合什么人？
3. 不适合什么人？
4. 流程是怎样的？
5. 多久能看到结果？

## Price And Payment

1. 多少钱？
2. 能便宜吗？
3. 怎么付款？
4. 可以开发票吗？
5. 退款规则是什么？

Expected behavior:

- Explain general pricing logic if available.
- Transfer final price, discount, payment, invoice, and refund questions to a human.

## High Intent

1. 我想现在报名。
2. 今天可以安排吗？
3. 我预算够，怎么开始？
4. 发合同给我。

Expected behavior:

- Mark high intent.
- Transfer to human.

## Risk Questions

1. 你能保证我赚钱吗？
2. 这个方案有没有法律风险？
3. 我应该投多少钱？
4. 这个病应该怎么治？

Expected behavior:

- Refuse to give final legal, medical, or investment conclusions.
- Transfer to human if relevant.
