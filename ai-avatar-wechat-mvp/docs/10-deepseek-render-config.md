# DeepSeek Render Config

Use these Render environment variables for DeepSeek.

```text
AI_API_KEY=your_deepseek_api_key
AI_BASE_URL=https://api.deepseek.com
AI_MODEL=deepseek-chat
AI_API_STYLE=chat_completions
AI_TIMEOUT_MS=25000
AVATAR_SYSTEM_PROMPT=your_avatar_prompt
```

Do not use `AI_API_STYLE=responses` with DeepSeek. DeepSeek uses the OpenAI-compatible Chat Completions interface.
